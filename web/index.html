How it works

Your game talks to Lobbi only to find other players. Game traffic goes player to player.

1

Create or join a lobby

One call: joinOrCreate, or join by code. The first player in becomes the host and runs the game.

2

Connect directly

Lobbi sets up the connection between players, so they connect peer to peer with no game server in the middle.

3

Relay if needed

When a network blocks direct connections, traffic goes through a relay. Relay access is granted only to players inside a lobby.

What you get

Lobbies

Join codes, quick match by name, a public list with paging, passwords and kick.

Fast and safe channels

Unreliable for positions, reliable for events. Large messages on the safe channel are split and reassembled for you.

Adaptive player cap

Lobbi measures the host's upload and watches tick time, then raises or lowers how many players new joins can admit.

Locked-down keys

Each game has a public key tied to an allow-list of origins, plus rate limits and per-network caps.

Reconnects

A short network blip does not end the lobby. Clients resume their session within a grace window.

Tiny SDK

One ES module, no dependencies, TypeScript types included.

Add it to your game

Install the SDK, connect with your game's public key, then join or create a lobby.

import { Lobbi } from 'lobbi';

const net = await Lobbi.connect({ key: 'pk_...', url: 'wss://api.example.com' });
const lobby = await net.joinOrCreate({ name: 'room-1', max: 8 });

lobby.on('message', (from, data) => { /* apply game state */ });
lobby.on('closed', (reason) => { /* lobby over: back to the menu */ });

lobby.send(myInput);                 // players send to the host
if (lobby.isHost) lobby.reportTick(ms); // lets the server adapt the player cap

Good to know

  • The host is the authority. The lobby creator runs the game, so a host can cheat. That is fine for casual games, not for competitive ones.
  • If the host leaves, the lobby closes. Host migration is planned but not built yet.
  • Star topology. Players connect to the host, not to each other.
  • Direct connections reveal IP addresses to the other players in the lobby.
  • It is early. v0.1 works end to end in testing, but expect rough edges.

Questions

Is it free?

Yes, the Free tier costs nothing. Paid tiers with higher limits are planned but not available yet.

Do I need to run a server?

No. Create an API in the dashboard, copy its key into your game and you are done.

What if players cannot connect directly?

Their traffic goes through a relay. Relay bandwidth is the main cost, so each API has a total relay allowance and relay access is only granted to players inside a lobby.

What kind of games fit?

Small casual games with a handful of players per lobby, where one player can host.
